Endereço do site:
https://ativadorunitv.github.io/revendedor/

Área administrativa:
https://ativadorunitv.github.io/revendedor/admin.html

COMO GERENCIAR CLIENTES

1. Abra o admin.html publicado.
2. Entre com a senha do administrador.
3. A página lerá automaticamente o senhas.json publicado.
4. Crie um cliente, altere um nome, troque uma senha ou bloqueie um acesso.
5. Clique em "Baixar senhas.json".
6. Substitua o senhas.json da raiz do repositório pelo arquivo baixado.
7. Aguarde o GitHub Pages publicar a alteração.

IMPORTANTE

O GitHub Pages é um serviço estático. A página administrativa consegue ler o
JSON publicado e preparar uma versão atualizada, mas não consegue gravar no
repositório sem um servidor ou uma credencial do GitHub. Por segurança, não
coloque um token do GitHub dentro do HTML.

As senhas dos clientes são gravadas no JSON somente como hash SHA-256. O campo
"bloqueado": true impede o acesso do cliente. Com "bloqueado": false, o acesso
fica liberado.
